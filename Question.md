# Sorting Algorithm Analysis — Assignment Question

## Question

A social media application needs to sort the following fixed-length IDs:

**324, 125, 456, 218, 102, 389, 275, 147**

### Tasks

**a)** Implement MergeSort and execute it on the given data. Record the contents of the array after each digit position is processed.

**b)** Implement Quick Sort for the same input. Record the important partition results and final sorted sequence.

**c)** Analyse MergeSort and Quick Sort using:

- Number of passes/partitions
- Comparisons or major operations
- Time complexity
- Additional space

Based on the execution and theoretical analysis, determine which method is more appropriate for large fixed-length keys.
